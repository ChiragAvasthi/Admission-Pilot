# AdmissionPilot - Frontend

This is the enterprise dashboard for AdmissionPilot, a React 19 application built with Vite and strictly typed with TypeScript. It serves as the primary interface for users to orchestrate and monitor specialized Business Agents without interacting with them directly.

## Tech Stack
- **Framework**: React 19, Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand (Client State), TanStack Query (Server State)
- **Routing**: React Router DOM
- **Forms**: React Hook Form + Zod
- **API Client**: Axios

## Folder Structure

```
frontend/
├── src/
│   ├── app/           # Global providers (e.g., QueryClientProvider)
│   ├── components/    # Reusable primitive UI components
│   ├── features/      # Domain-specific modules (e.g., ChatPanel)
│   ├── layouts/       # Structural layouts (AppLayout, Sidebar, TopNav)
│   ├── pages/         # Route components (Dashboard, Uploads, Execution, etc.)
│   ├── services/      # Axios API integrations with the Python backend
│   ├── store/         # Zustand global state (Theme, Current Project context)
│   ├── styles/        # Global CSS and Tailwind directives
│   └── types/         # TypeScript definitions for backend Pydantic models
```

## Backend Integration
This frontend heavily relies on the Python backend via the Axios client configured in `src/services/api.ts`.
- **Uploads (`/api/uploads`)**: Handles document ingestion for the Document Intelligence Agent.
- **Execution (`/api/execute`)**: Triggers LangGraph workflows in the backend Master Agent.
- **Reports (`/api/reports`)**: Fetches markdown strings generated by the Report Generation Agent, which are then rendered using `react-markdown`.

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Runs the app in development mode.
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### `npm run build`
Compiles TypeScript and builds the app for production to the `dist` folder.

### `npm run preview`
Locally preview the production build.

### `npx vitest`
Launches the test runner in watch mode.

## Installation & Setup

1. Ensure you have Node.js 20+ installed.
2. Run `npm install` in the `/frontend` directory.
3. Configure your `.env` file (e.g., `VITE_API_URL=http://localhost:8000/api`).
4. Run `npm run dev`.
